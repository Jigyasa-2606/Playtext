# Playtext

Chrome extension that turns a YouTube video link into a clean, readable transcript.

## Install in Chrome

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this folder
5. Pin Playtext from the puzzle-piece menu

If the extension is already loaded, click **Reload** on its card, then grant the extra permission if Chrome asks.

## Use it

- Stay on the YouTube video tab, then click **Generate transcript**
- Copy, search, download `.txt` / `.srt`, or open **Full view**
